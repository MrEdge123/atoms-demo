# 高级网页 UI 设计参考手册（Agent 版）

> **用途**：本文档提炼自 Awwwards、Godly、SiteInspire、Minimal Gallery、Mobbin、Lapa Ninja、Typewolf、Pangram Pangram 等顶级设计平台上的获奖/高分作品规律。
> **使用方式**：根据用户需求的「场景」直接查阅对应章节，套用其中的设计决策清单；通用原则（第一、二章）在所有场景中生效。
> **文档版本**：2026-11，基于 2025–2026 年设计趋势。

---

## 一、通用设计原则（所有场景必读）

### 1.1 高级感 = 克制 + 精度

获奖设计的共性不是"加了多少东西"，而是"删到不能再删之后，每一处细节都被精确处理"：

- **少即是多**：一个页面只保留 1 个视觉焦点、1 套主色、1 个核心动效。
- **精度补偿克制**：因为元素少，间距、字重、圆角、阴影的每一像素都会暴露。高级感来自 `letter-spacing: -0.02em` 这种级别的微调。
- **留白是设计元素**：留白不是"没做完"，是主动构图。获奖站点的留白占比普遍在 40%–60%。

### 1.2 层级三件套

任何界面建立视觉层级只靠三个杠杆，按优先级：

1. **尺寸对比**（最重要）：标题与正文至少 2.5 倍以上字号差；高级感页面常见 5–10 倍。
2. **字重对比**：Bold/Light 组合优于 Regular/Regular。
3. **色彩明度对比**：正文 `#111` 附近、次要文字 `#666–#999`、辅助信息 50% 透明度——靠灰阶而非彩色区分层级。

### 1.3 一致性系统

- **间距用倍数体系**：以 4px 或 8px 为基准（4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128），禁止出现 13px、27px 这类游离值。
- **圆角一个家族**：全站只用 1–2 种圆角半径（如 8px 卡片 + 999px 胶囊按钮）。
- **颜色有角色**：每个颜色必须有明确职责（品牌主色 / 文字 / 背景 / 强调 / 语义色），不允许"随便选个好看的颜色"。

### 1.4 性能纪律

Awwwards 获奖站点的隐藏共性：**动画再炫也不阻塞阅读**。
- 动效时长 200–600ms，缓动用 `ease-out` 或自定义 cubic-bezier，禁止线性匀速。
- 首屏加载优先，装饰性动效延迟加载。
- 移动端必须可用：获奖作品全部通过响应式评审。

## 二、排版系统（Typography）

排版是高级网页设计的第一生产力。Awwwards 评审中排版质量几乎决定上限。

### 2.1 字体选择策略

| 气质 | 字体方向 | 代表组合 |
|---|---|---|
| 现代科技感 | 几何无衬线 | Inter / Space Grotesk / Neue Haas |
| 高级编辑感 | 衬线 + 无衬线混搭 | 衬线标题（GT Super / PP Editorial）+ 无衬线正文 |
| 极简日系 | 细字重无衬线 + 大留白 | Noto Sans JP Light / ヒラギノ |
| 中文场景 | 思源黑体/思源宋体、霞鹜文楷；标题可用思源宋体 Bold 营造编辑感 | — |

**规则**：全站最多 2 个字体家族；标题与正文字体形成"对比但不冲突"的关系。

### 2.2 字号阶梯（Modular Scale）

推荐比率 1.25（Major Third）或 1.333（Perfect Fourth）：

```
12 → 14 → 16(正文基准) → 20 → 25 → 31 → 39 → 49 → 61 → 76 → 96+
```

- 正文：16–18px，行高 1.5–1.7
- 大标题（Hero）：48–96px，行高 1.05–1.15，字距收紧（-0.02em ~ -0.04em）
- **超大标题趋势**：Hero 标题占屏宽 70% 以上是 2025–2026 获奖站点的标志性手法（Oversized Typography）

### 2.3 段落排版细则

- 行长控制：英文 45–75 字符/行，中文 20–35 字/行
- 段间距用空行而非首行缩进（网页惯例）
- 中英文混排时，中英文之间加空隙（`pangu` 规则）
- 数字用等宽数字（`font-variant-numeric: tabular-nums`），尤其在表格和数据展示中

### 2.4 动态字体（Kinetic Typography）

进阶手法，用于 Hero 区域和品牌强调处：
- 滚动时字母拉伸、错位、重组（参考 Mat Voyce）
- 光标跟随的文字变形
- **红线**：动画期间文字必须始终可读；阅读区域正文禁用动态字体。

## 三、场景化设计指南

以下按用户常见需求场景组织，每个场景给出：调性关键词 → 布局模式 → 配色建议 → 排版要点 → 动效建议 → 参考来源。

---

### 场景 A：品牌官网 / 产品营销页（Landing Page）

**调性**：视觉冲击、叙事感、转化导向

**布局模式**：
- Hero 全屏：超大标题（5–10 倍正文字号）+ 一句话价值主张 + 1 个主 CTA
- 滚动叙事（Scroll Storytelling）：一屏一个信息点，禁止一屏塞多主题
- 社会证明区：Logo 墙 / 数据 / 用户评价，用网格对齐
- 结尾 CTA 重复出现，首尾呼应

**配色**：品牌主色占 10% 以下作为强调；大面积中性色（白 / 米白 / 深黑）；渐变只用于装饰层不用于文字。

**排版**：标题是视觉主体，可尝试衬线大标题营造编辑感；正文短句化，每段不超过 3 行。

**动效**：滚动触发的渐入（fade-in + translateY 20–40px）；视差滚动层次；Hero 可用 WebGL/粒子背景但要保证文字对比度。

**反模式**：轮播图（转化率杀手）、弹窗打断、超过 3 个 CTA 抢注意力。

**参考**：Lapa Ninja、Land-book、Godly

---

### 场景 B：SaaS 产品界面 / 后台仪表盘（Dashboard）

**调性**：清晰、高效、可信

**布局模式**：
- 经典框架：左侧导航栏（240px 左右）+ 顶部工具栏 + 内容区
- 卡片网格：12 列网格，卡片间距 16–24px，卡片内边距 20–24px
- 数据密度分级：概览页低密度（大数字 + 趋势图），明细页高密度（表格）

**配色**：
- 浅色模式为默认；深色模式需重新设计灰阶层级（不是简单反色）
- 语义色克制：成功绿 / 警告橙 / 错误红 / 信息蓝，各一色一阶
- 图表配色从一个主色出发做明度展开

**排版**：
- 无衬线单一字体家族，数字用 tabular-nums
- 数据可视化中：大数字 32–48px，标签 12–13px 灰色
- 表格：行高 40–48px，表头小字灰色大写或加粗

**动效**：微交互为主——按钮 hover 状态、加载骨架屏、数字滚动；禁止装饰性动画。

**反模式**：彩虹色图表、3D 饼图、无意义的卡片阴影叠加。

**参考**：Mobbin、Refero、UI Garage

---

### 场景 C：个人作品集 / 创意工作室网站

**调性**：个性表达、艺术方向、 memorable

**布局模式**：
- 允许打破网格：不对称布局、出血图片、重叠元素
- 作品列表是核心：大图 + 少文字，hover 出交互预览
- 导航可做实验：全屏菜单、侧边竖排导航

**配色**：可用大胆单色（如全站克莱因蓝 / 亮黄）或黑白 + 作品图自身色彩。

**排版**：
- 这是最适合动态字体和超大标题的场景
- 可混排横竖文字、中英文混排制造节奏
- 工作室名/个人名本身当作图形元素处理

**动效**：页面转场动画（像镜头切换）、光标自定义、图片跟随鼠标的位移。这是唯一允许"炫技"的场景，但仍需性能纪律。

**反模式**：模板感（和别人的作品集长得一样）、作品图太小、加载动画过长。

**参考**：Awwwards SOTD、Godly、Minimal Gallery

---

### 场景 D：电商 / 消费产品页

**调性**：品质感、信任、购买引导

**布局模式**：
- 产品图是绝对主角：占版面 50% 以上，支持放大看细节
- 购买信息区固定结构：名称 → 价格 → 规格选择 → CTA → 保障信息
- 故事化区块：材质/工艺/场景图穿插（参考 Supima Cotton 的叙事滚动）

**配色**：从产品中取色；高端线用米白/暖灰/深棕等自然色系；快消可用高明度撞色。

**排版**：产品名衬线体增加质感；价格数字醒目但不过大；描述文字简短分点。

**动效**：产品图滚动放大/旋转；加入购物车的确认反馈动画；图片懒加载的模糊过渡。

**反模式**：促销信息轰炸、过多badge角标、低质量素材图。

**参考**：Awwwards 电商分类、Lapa Ninja 电商筛选

---

### 场景 E：内容 / 媒体 / 博客（Editorial）

**调性**：阅读体验优先、杂志感、沉浸

**布局模式**：
- 正文列宽居中：600–720px，两侧大留白
- 编辑式网格：首字下沉、拉宽引用块（pull quote）、出血大图打断节奏
- 文章卡片列表：大图卡片 + 清晰的分类标签

**配色**：纸张色系背景（纯白 / 米白 #FAFAF7），文字近黑（#1A1A1A 而非纯黑 #000）；深色阅读模式可选。

**排版**（本场景排版权重最高）：
- 标题衬线体（或思源宋体），正文可衬线可无衬线
- 正文字号 17–19px，行高 1.6–1.8
- 行长严格控制（见 2.3），段落间距 ≥ 1.5em
- 图片说明、引用、注释的样式系统要完整

**动效**：极简——阅读进度条、图片渐入即可。滚动效果不许干扰阅读。

**参考**：Siena Film Foundation（Awwwards 2025 三月最佳）、Minimal Gallery、Medium

---

### 场景 F：移动端 H5 / App 界面

**调性**：触达效率、拇指友好、轻快

**布局模式**：
- 拇指热区：核心操作放在屏幕下半部分
- 点击目标 ≥ 44×44px（iOS）/ 48×48px（Android）
- 底部导航 3–5 个入口，超过用"更多"收纳

**配色**：与品牌 Web 端一致，但注意户外强光下的对比度（正文对比度 ≥ 4.5:1）。

**排版**：
- 正文 15–16px，层级靠字重拉开
- 标题 20–28px 即可，移动端不适合超大标题（占屏比过高）

**动效**：手势驱动的物理感动画（弹簧曲线）；转场 300ms 内；下拉刷新等系统惯例不重新发明。

**反模式**：把桌面布局直接缩小、hover 态依赖、文字小于 12px。

**参考**：Mobbin（最强移动参考库）、Pttrns、Screenlane

---

### 场景 G：深色模式 / 科技未来感专题

**调性**：沉浸、氛围、高级感

**核心要点**（参考 Dark Mode Design 精选站的手法）：
- 背景不是纯黑：用 #0A0A0F ~ #121218 的深蓝黑/炭黑
- 灰阶层级靠明度阶梯：背景 → 卡片 +4~8% 明度 → 浮层再 +4~8%
- 阴影失效，改用 1px 半透明白边（rgba(255,255,255,0.06~0.1)）分隔层级
- 强调色在深色上更亮：选高明度版本，注意光晕效果（glow）要克制
- 图片需要单独处理：降低亮度/对比度使其融入暗背景

**适用**：开发者工具、AI 产品、音视频产品、夜间场景产品。

## 四、快速决策流程（Agent 执行用）

接到设计需求时按此顺序确认：

```
1. 场景识别 → 查第三章对应场景（A–G）
2. 气质确认 → 问用户或推断：极简/编辑/科技/活泼/奢华
3. 字体方案 → 查 2.1 表格选定字体组合
4. 字号阶梯 → 用 2.2 的模数比例生成
5. 间距体系 → 8px 基准倍数
6. 配色 → 主色1 + 中性色阶 + 语义色，深色场景查场景 G
7. 动效 → 按场景建议选 1–2 种，全部 200–600ms ease-out
8. 交付前自查 → 用第五章清单
```

## 五、交付前自查清单（Checklist）

**排版**
- [ ] 全站字体家族 ≤ 2 个
- [ ] 字号全部来自同一模数阶梯
- [ ] 正文行高 1.5–1.8，行长在规范内
- [ ] 中英文混排加空隙，数字用等宽数字

**间距与布局**
- [ ] 所有间距是 4/8px 的倍数
- [ ] 圆角家族 ≤ 2 种
- [ ] 页面只有一个视觉焦点

**颜色**
- [ ] 主色占比 < 10%，中性色为主
- [ ] 文字对比度 ≥ 4.5:1（正文）/ 3:1（大标题）
- [ ] 语义色（红绿黄蓝）不与品牌色冲突

**动效**
- [ ] 时长 200–600ms，非线性缓动
- [ ] 动画不阻塞阅读与操作
- [ ] 提供 prefers-reduced-motion 降级

**响应式**
- [ ] 移动端点击目标 ≥ 44px
- [ ] 移动端无横向滚动
- [ ] 桌面/移动两端都验证过
